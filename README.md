# Acronym Academy

A learning site explaining common software-engineering acronyms, with a quiz to test recall.

## Features

- Lesson pages for API, CRUD, REST, MVC, SOLID, DRY, KISS, YAGNI, TDD and CI/CD
- Explanations, examples and benefits/pitfalls for each concept
- Multiple-choice quiz with a completion screen

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- React Router
- TanStack Query
- lucide-react

## Running locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## How it was built

Built with Lovable (AI app builder) under Matthew Thornhill's direction as a learning/exploration project.
